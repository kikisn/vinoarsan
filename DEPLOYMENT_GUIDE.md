# Contact Form Deployment Guide with SMTP

## Overview
This guide will help you deploy the Vino Arsan contact form with **professional SMTP email delivery** using PHPMailer.

## Quick Start (5 Minutes)

### Step 1: Upload Files to Server
Upload these files to your web server:
```
contact.html
contact-handler.php
email-config.example.php
composer.json
scripts.js
styles.css
```

### Step 2: Install PHPMailer
SSH into your server or use your hosting control panel's terminal:
```bash
cd /path/to/your/website
composer install
```

This creates a `vendor/` folder with PHPMailer.

### Step 3: Configure SMTP Settings
```bash
# Copy the example config
cp email-config.example.php email-config.php

# Edit with your SMTP credentials
nano email-config.php  # or use your preferred editor
```

**For Gmail (Easiest for Testing):**
1. Go to https://myaccount.google.com/apppasswords
2. Generate an app password
3. Update `email-config.php`:
```php
'smtp' => [
    'enabled' => true,
    'host' => 'smtp.gmail.com',
    'port' => 587,
    'encryption' => 'tls',
    'auth' => true,
    'username' => 'your-email@gmail.com',
    'password' => 'xxxx xxxx xxxx xxxx',  // 16-char app password
],
```

### Step 4: Test the Form
1. Visit your contact page
2. Fill out the form
3. Check your inbox for the email!

## Detailed Setup Instructions

### Option 1: Gmail (Free - Good for Testing)

**Pros:** Free, easy to set up, reliable
**Cons:** 500 emails/day limit, requires 2FA

**Setup:**
1. Enable 2-Factor Authentication on your Google account
2. Visit https://myaccount.google.com/apppasswords
3. Create an app password for "Mail"
4. Update `email-config.php`:

```php
'smtp' => [
    'enabled' => true,
    'host' => 'smtp.gmail.com',
    'port' => 587,
    'encryption' => 'tls',
    'auth' => true,
    'username' => 'your-email@gmail.com',
    'password' => 'your-16-char-app-password',
],
'from_email' => 'your-email@gmail.com',
'from_name' => 'Vino Arsan Contact Form',
```

### Option 2: SendGrid (Professional - Recommended)

**Pros:** Professional, 100 emails/day free, better deliverability
**Cons:** Requires signup

**Setup:**
1. Sign up at https://sendgrid.com (Free tier available)
2. Create API key: Settings → API Keys → Create API Key
3. Update `email-config.php`:

```php
'smtp' => [
    'enabled' => true,
    'host' => 'smtp.sendgrid.net',
    'port' => 587,
    'encryption' => 'tls',
    'auth' => true,
    'username' => 'apikey',  // literally the word "apikey"
    'password' => 'SG.your-api-key-here',
],
'from_email' => 'noreply@vinoarsan.com',
'from_name' => 'Vino Arsan Contact Form',
```

### Option 3: Custom Domain Email (cPanel/Hosting)

**Pros:** Professional email address (noreply@vinoarsan.com)
**Cons:** Requires email account setup

**Setup:**
1. Create email account in cPanel: `noreply@vinoarsan.com`
2. Find SMTP settings in cPanel (usually in email section)
3. Update `email-config.php`:

```php
'smtp' => [
    'enabled' => true,
    'host' => 'mail.vinoarsan.com',  // or smtp.vinoarsan.com
    'port' => 587,  // or 465 for SSL
    'encryption' => 'tls',  // or 'ssl'
    'auth' => true,
    'username' => 'noreply@vinoarsan.com',
    'password' => 'your-email-password',
],
'from_email' => 'noreply@vinoarsan.com',
'from_name' => 'Vino Arsan Contact Form',
```

## Troubleshooting

### Problem: "Email system not configured"
**Solution:** Run `composer install` in your project directory

### Problem: Emails not arriving
**Possible causes:**
1. **Check spam folder** - Emails might be filtered
2. **Wrong credentials** - Verify SMTP username/password
3. **Firewall blocking** - Check server allows outbound SMTP connections
4. **Debug mode** - Enable debugging:
   ```php
   'debug' => true,
   ```

### Problem: "SMTP Error: Could not authenticate"
**Solution:**
- Gmail: Ensure you're using App Password, not regular password
- SendGrid: Username should be literally "apikey"
- Custom: Verify email account exists and password is correct

### Problem: "Connection timed out"
**Solution:**
- Check firewall allows port 587/465
- Try alternate port (587 or 465)
- Contact hosting provider about SMTP restrictions

### Problem: Form submits but no email
**Check:**
1. PHP error logs: `tail -f /var/log/php-errors.log`
2. Enable debug mode in `email-config.php`
3. Check server's mail logs
4. Verify `contact-handler.php` has read access to `email-config.php`

## Advanced Configuration

### Enable SMTP Debugging
For troubleshooting connection issues:
```php
'debug' => true,  // Shows detailed SMTP conversation
```

### Use Different SMTP for Different Environments
```php
// In email-config.php
$isProduction = ($_SERVER['HTTP_HOST'] === 'vinoarsan.com');

return [
    'smtp' => [
        'enabled' => true,
        'host' => $isProduction ? 'smtp.sendgrid.net' : 'smtp.gmail.com',
        'username' => $isProduction ? 'apikey' : 'test@gmail.com',
        // ... etc
    ],
];
```

### Add CC/BCC Recipients
In `contact-handler.php` around line 312:
```php
$mail->addAddress($config['recipient_email'], $config['recipient_name']);
$mail->addCC('manager@vinoarsan.com');  // Carbon copy
$mail->addBCC('archive@vinoarsan.com'); // Blind carbon copy
```

### Custom Email Templates
Edit the HTML in `contact-handler.php` starting at line 156 to customize email design.
